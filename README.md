# 📄 Online Resume Builder

## 📌 Project Description

The **Online Resume Builder** is a simple web application that allows users to create a professional resume by entering their personal and academic details. The application generates a clean resume preview, which can be printed or downloaded as a PDF.

This project is developed using **HTML, CSS, and JavaScript** and stores user information using the browser's **Local Storage**.

---

## ✨ Features

* Enter personal details
* Add career objective
* Add education details
* Add technical skills
* Add projects
* Add LinkedIn profile
* Add GitHub profile
* Add certificates
* Add strengths
* Add languages known
* Add hobbies
* Resume preview page
* Print resume
* Download resume as PDF
* Edit resume information

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* html2pdf.js

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open **index.html** in your web browser.
4. Fill in all the required details.
5. Click **Generate Resume**.
6. Preview your resume.
7. Print or download it as a PDF.
